# Кластеризация штаммов бактерий

Учебный проект по задаче №5: веб-приложение для анализа похожести штаммов бактерий, иерархической кластеризации и автоматического выбора числа кластеров.

Приложение позволяет использовать демонстрационные данные или загрузить собственный CSV-файл, посмотреть результаты на интерактивных графиках, изучить характеристики кластеров и скачать таблицы с результатами.

Проект поддерживает **Python 3.10–3.13** в Windows и проверен на **Python 3.11.3**. Подходящая версия выбирается автоматически.

## 1. Что реализовано

- генерация 20 демонстрационных штаммов с воспроизводимым результатом (`RandomState(123)`);
- загрузка и проверка пользовательского CSV;
- стандартизация пяти количественных признаков;
- one-hot кодирование источника выделения;
- расчёт трёх компонент попарных расстояний и их взвешенного объединения;
- иерархическая кластеризация методом Уорда;
- выбор оптимального `k` по коэффициенту силуэта;
- PCA-проекция, дендрограмма и график качества разбиений;
- таблицы принадлежности к кластерам и средних характеристик групп;
- автоматические текстовые пояснения результатов;
- выгрузка четырёх результатов в CSV.

Для демонстрационного набора получается:

- **оптимальное число кластеров:** `5`;
- **лучший коэффициент силуэта:** `0,402131`;
- **размеры кластеров:** 6, 3, 7, 2 и 2 штамма.

Эти значения относятся именно к синтетическому набору из задания. При загрузке другого CSV они изменятся.

## 2. Запуск в Windows

### Запуск одним нажатием

1. Скопируйте папку проекта на компьютер и дважды нажмите `run.bat`. Ничего заранее устанавливать или настраивать вручную не требуется.
2. При первом запуске дождитесь автоматической настройки окружения. Для скачивания Python и библиотек нужен интернет.
3. Дождитесь открытия браузера или перейдите вручную по адресу:

   <http://127.0.0.1:8501>

4. Для остановки нажмите `Ctrl+C` в окне терминала или закройте это окно.

`run.bat` самостоятельно:

- определяет абсолютный путь к папке проекта, поэтому его можно запускать из любого каталога, с OneDrive или USB-диска;
- ищет Python 3.10–3.13 через Python Launcher и команды `python` / `python3`;
- если подходящего Python нет, скачивает официальный установщик Python 3.11 с python.org, проверяет его цифровую подпись и устанавливает Python локально в `.python` без добавления в `PATH` и замены системного Python;
- создаёт изолированное окружение `.venv`, а повреждённое или неподходящее окружение пересоздаёт;
- при каждом запуске проверяет версии из `requirements.txt`, устанавливает недостающие библиотеки и исправляет несовместимые версии;
- выполняет `pip check` и проверяет импорт всех необходимых библиотек;
- запускает `app.py` по абсолютному пути только на локальном адресе `127.0.0.1`.

После первой успешной настройки повторный запуск обычно не требует интернета: уже подходящие библиотеки не скачиваются заново. Если `requirements.txt` изменился или версии в `.venv` были изменены, для их исправления снова понадобится интернет.

Автоматическая установка Python рассчитана на 64-разрядную Windows. На другой архитектуре заранее установите поддерживаемый Python 3.10–3.13. Порт `8501` должен быть свободен.

### Запуск без run.bat

Из папки проекта можно выполнить команду:

```bat
.venv\Scripts\python.exe -m streamlit run "%~dp0app.py" --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

В интерактивном терминале вместо `"%~dp0app.py"` укажите полный путь к `app.py`.

## 3. Работа с приложением

В боковой панели выбирается источник данных:

- **Демонстрационные данные** — расчёт запускается автоматически на наборе из условия;
- **Загрузить CSV** — приложение ждёт файл пользователя, проверяет его и затем выполняет тот же расчёт.

В верхней части страницы показываются оптимальное `k`, лучший силуэт и число штаммов. Ниже находятся шесть вкладок:

| Вкладка | Содержимое |
|---|---|
| **PCA** | Интерактивная двумерная проекция штаммов с цветами кластеров и пояснением графика. |
| **Дендрограмма** | Дерево иерархических объединений и линия разреза для выбранного `k`. |
| **Подбор k** | График и таблица коэффициента силуэта для всех проверенных значений `k`, формула метрики. |
| **Кластеры** | Принадлежность штаммов к группам, средние характеристики и автоматическая интерпретация каждого кластера. |
| **Методика** | Подробное описание предобработки, расстояний, метода Уорда, силуэта и PCA. |
| **Данные** | Проверенная исходная таблица и описание её столбцов. |

## 4. Формат входного CSV

Файл должен быть разделён запятыми и содержать следующие обязательные столбцы:

| Столбец | Тип | Назначение |
|---|---|---|
| `strain_id` | строка | Уникальный идентификатор штамма. |
| `growth_rate` | число | Скорость роста. |
| `product_yield` | число | Выход продукта. |
| `pH_tolerance` | число | Устойчивость к условиям pH. |
| `GC_content` | число | GC-состав генома, %. |
| `genome_size_mbp` | число | Размер генома в миллионах пар оснований. |
| `has_plasmid` | `0` или `1` | Отсутствие или наличие плазмиды. |
| `source` | `soil`, `water`, `gut` | Источник выделения: почва, вода или кишечник. |

Пример:

```csv
strain_id,growth_rate,product_yield,pH_tolerance,GC_content,genome_size_mbp,has_plasmid,source
S01,1.20,3.09,7.50,58.39,3.96,1,water
S02,0.79,3.62,5.46,56.72,5.08,1,water
S03,0.73,3.31,6.27,57.50,4.66,0,gut
```

Перед расчётом программа проверяет:

- наличие обязательных столбцов и отсутствие повторяющихся названий столбцов;
- минимум три строки данных;
- отсутствие пропусков;
- непустые и уникальные `strain_id`;
- числовой тип и конечность значений количественных признаков;
- значения `has_plasmid` строго 0 или 1;
- допустимые значения `source`.

При ошибке приложение показывает сообщение на русском языке, а не запускает расчёт на некорректных данных. Дополнительные столбцы сохраняются в таблице, но не участвуют в кластеризации.

## 6. Вычислительная часть

### 6.1. Предобработка

Пять количественных признаков стандартизируются через `StandardScaler`:

\[
z = \frac{x - \mu}{\sigma},
\]

где \(\mu\) — среднее признака, а \(\sigma\) — стандартное отклонение по набору (`ddof=0`). Это не даёт признакам с крупными числовыми шкалами доминировать только из-за единиц измерения.

`has_plasmid` остаётся бинарным признаком. `source` преобразуется через `pandas.get_dummies` в one-hot вектор. Для PCA эти блоки объединяются в одну матрицу признаков.

### 6.2. Матрицы расстояний

Для всех пар штаммов вычисляются:

1. **Евклидово расстояние** между стандартизованными количественными признаками.
2. **Расстояние Хэмминга** для `has_plasmid`. Для одного бинарного признака оно равно модулю разности значений.
3. **Евклидово расстояние** между one-hot векторами источника.

Каждая матрица нормируется на своё максимальное расстояние. Если максимум равен нулю, возвращается нулевая матрица, поэтому деления на ноль не происходит.

Итоговое расстояние:

\[
D = 0{,}6D_{numeric} + 0{,}2D_{plasmid} + 0{,}2D_{source}.
\]

Чем меньше значение, тем более похожи два штамма. Диагональ матрицы равна нулю, матрица симметрична. Веса заданы условием задачи, а не подбираются программой.

### 6.3. Кластеризация и выбор k

Итоговая матрица преобразуется в condensed-form через `squareform` и передаётся в:

```python
linkage(distance_matrix, method="ward")
```

Для каждого допустимого `k` метки получаются через:

```python
fcluster(linkage_matrix, t=k, criterion="maxclust")
```

Для 20 штаммов проверяются `k = 2, ..., 10`. Для наборов другого размера верхняя граница равна `min(10, n - 1)`.

Качество каждого разбиения оценивается по предвычисленной матрице расстояний:

```python
silhouette_score(distance_matrix, labels, metric="precomputed")
```

Силуэт отдельного объекта:

\[
s(i) = \frac{b(i)-a(i)}{\max(a(i),b(i))},
\]

где \(a(i)\) — среднее расстояние до объектов своего кластера, \(b(i)\) — среднее расстояние до ближайшего другого кластера. Чем выше среднее значение метрики, тем лучше разбиение по этому критерию.

Выбирается `k` с максимальным силуэтом. При равенстве значений предпочтение отдаётся меньшему `k`. Если из-за одинаковых высот объединения `fcluster` не формирует ровно `k` кластеров, такой вариант пропускается. Если допустимых разбиений нет, пользователь получает понятную ошибку.

### 6.4. PCA

`PCA(n_components=2)` применяется к объединённой предобработанной матрице: стандартизованные числовые признаки + плазмида + one-hot источник.

PCA используется **только для визуализации**. Кластеризация выполняется по полной взвешенной матрице расстояний, а не по двум компонентам. Доли объяснённой дисперсии выводятся на осях графика.

### 6.5. Сводка и текстовая интерпретация

Для каждого кластера рассчитываются:

- количество штаммов;
- средние значения пяти исходных, не масштабированных признаков;
- наиболее частый `source`; при равенстве частот выбирается первый по алфавиту;
- доля штаммов с плазмидой в блоке интерфейса с пояснениями.

Функция `cluster_feature_differences` дополнительно находит до двух признаков с наибольшим абсолютным отклонением среднего кластера от общего среднего, измеренным в стандартных отклонениях. Эти пояснения помогают читать результат, но **не участвуют в кластеризации**.

Функция `silhouette_description` также нужна только для текстовой интерпретации и не влияет на выбор `k`.

## 7. Основные функции `strain_clustering.py`

| Функция или объект | Назначение |
|---|---|
| `generate_demo_data()` | Создаёт воспроизводимый набор из 20 штаммов по диапазонам из задания. |
| `validate_data(data)` | Проверяет DataFrame и возвращает его очищенную копию. Ошибки выдаются как `DataValidationError`. |
| `_prepare_features(data)` | Выполняет стандартизацию, one-hot кодирование и собирает матрицу для PCA. |
| `_normalized_distances(features, metric)` | Строит и нормирует матрицу попарных расстояний для одного блока признаков. |
| `_distance_matrix_from_features(...)` | Объединяет компоненты с весами 0,6 / 0,2 / 0,2. |
| `compute_distance_matrix(data)` | Публичная функция для получения итоговой матрицы из исходного DataFrame. |
| `analyze_strains(data)` | Выполняет полный анализ: Ward, подбор `k`, PCA, метки и сводку. |
| `ClusteringResult` | Dataclass, через который расчётный модуль передаёт все результаты в интерфейс. |

`ClusteringResult` содержит очищенные данные, `optimal_k`, список пар `(strain_id, cluster_label)`, сводную таблицу, PCA-координаты, доли объяснённой дисперсии, матрицу расстояний, таблицу силуэтов и linkage-матрицу для дендрограммы.

## 12. Ограничения интерпретации

- Демонстрационные данные синтетические и случайные: кластеры в них иллюстрируют алгоритм, а не реальную биологическую структуру.
- Метод Уорда применяется к итоговой взвешенной матрице в соответствии с учебным заданием.
- На результат влияют выбранные признаки, веса и способ нормировки.
- Оптимальное по силуэту `k` не обязательно является единственно правильным с биологической точки зрения.
- Номера кластеров являются техническими метками и не обозначают качество или порядок групп.
- Похожесть по набору признаков сама по себе не доказывает родство или причинно-следственные связи.
